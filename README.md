# AI Placement Prediction System

## Description
This project predicts whether a student is likely to be placed based on academic and technical skills using Machine Learning.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Decision Tree
- Chart.js

## Features
- Placement Prediction
- Dashboard
- Pie Chart
- Bar Chart
- Student Statistics

## How to Run
1. Clone the repository
2. Install dependencies
3. Run app.py
4. Open http://127.0.0.1:5000
